# Implementation specification for LLM recovery in dynamic embodied cooperation

This repository accompanies the manuscript **"Design Choices for LLM Recovery in Dynamic Embodied Cooperation."** Its purpose is limited to recording the implementation-level semantics and fixed settings used in the manuscript evaluation.

The specification is available at [`docs/implementation_rules.md`](docs/implementation_rules.md).

## Scope

This is a documentation-only repository. It does **not** release the full C-WAH/VirtualHome runtime, executable recovery code, model credentials, private intervention routes, terminal-audit answers, raw experimental logs, or a standalone reproduction package. The rules document should therefore be read as a manuscript-linked specification of the evaluated controller, not as an executable software release.
